+2.1 Purpose. The machine looks for trading patterns in NSE stocks, proves or disproves each with real money maths, and trades only proven ones on paper, by itself, every day. Most days will say "0 promoted". That is the machine working.

+2.2 The grid (data). Rows = one stock at one minute, 2020 to today (~210 F&O stocks, plus NIFTY/BANKNIFTY futures bars); daily rows are stacked from minutes. Columns = rulers. +2.3 Rulers. One number per stock per bar. [redacted]'s 35 stay exactly as they are; the Claude Price Engine adds wider families (price/trend, volume, volatility, flows, market state, calendar; options and order-book only once recorded). +
+2.4 A pattern = condition + direction + hold + exit.
+- Buckets: each ruler's readings are cut into a few equal-count slices from the stock's own history (or across stocks on the day). Any slice can be the bucket — top, bottom or middle — and two neighbouring slices may be merged. Edges are always computed; the number of slices is a declared convention (reason + sensitivity stated), kept small.
+- Condition: one or two rulers each in a bucket, true in the same row. Any mix of reactive and predictive rulers.
+- Fires: the rows where the condition is true. Their answer columns are the pattern's record. Both directions are tested.
+- Hold: the pattern keeps the answer column where net profit is best above the cost floor; nothing under an hour survives costs. Exits (fixed stop, time, trailing) are separate patterns from the same condition. Patterns never become rulers.
+- Conditions are checked on finished bars: daily patterns at the close, intraday patterns each finished bar.

Reason: the luck bar rises with the number of patterns competing for promotion; thousands can be judged honestly on six years, millions cannot.

+2.6 Two bars. Admission (past data): the pattern's history split by years, fitted on some, tested on years it never saw, costs inside, near-copies merged — passing is permission to enter the paper desk at tiny size, a shortlist, not proof. Near-copies are merged and judged as one. Instances, not variety: a pattern rises or falls only on its own days of proof.

+A FORECAST ruler (here the HAR volatility forecast) must pass its own exam before it may sit on the shelf: fit on
+the chronological TRAIN split, score on TEST against the NAIVE forecast (yesterday's value / random walk). It
+enters as a FORECAST ruler ONLY if it beats naive by MORE THAN the measured standard error of the loss difference
+(§5.1); otherwise it is kept as a STATE ruler (its inputs), never as a forecast. No look-ahead: the split is
+chronological and the fit sees only TRAIN.

+HAR lags (1 daily, 5 weekly, 22 monthly) are the model's DEFINING structure, not tuned thresholds — passed as a

+def har_features(rv, lags=(1, 5, 22)):
+    """Trailing HAR features: for each t, the mean realised vol over the last `lag` observations (inclusive of t).
+    All trailing => PIT (a feature at t never uses rv after t). Returns a DataFrame aligned to rv.index."""
+    d, w, m = lags
+    return pd.DataFrame({
+        "rv_d": rv.rolling(int(d)).mean(),
+        "rv_w": rv.rolling(int(w)).mean(),
+        "rv_m": rv.rolling(int(m)).mean(),
+    })
+
+
+def _fit_ols(X, y):
+    A = np.column_stack([np.ones(len(X)), X])
+    coef, *_ = np.linalg.lstsq(A, y, rcond=None)
+    return coef
+
+
+def _predict(coef, X):
+    return np.column_stack([np.ones(len(X)), X]) @ coef
+
+
+def exam(rv, train_frac=0.7, lags=(1, 5, 22)):
+    """Fit HAR on TRAIN, forecast next-day RV on TEST, compare to the naive (previous-value) forecast. Returns
+    har_rmse, naive_rmse, margin (naive-har mean squared-error gain), se (its standard error), beats_naive, and
+    decision FORECAST/STATE. beats_naive == margin > se (beats naive by more than one measured SE, §5.1)."""
+    feats = har_features(rv, lags)
+    target = rv.shift(-1)                                   # predict next day's RV
+    df = pd.concat([feats, target.rename("y"), rv.rename("naive")], axis=1).dropna()
+    n = len(df)

+                "beats_naive": False, "decision": "STATE", "n": n}
+    cut = int(n * train_frac)
+    Xtr, ytr = df[["rv_d", "rv_w", "rv_m"]].iloc[:cut].values, df["y"].iloc[:cut].values
+    Xte, yte = df[["rv_d", "rv_w", "rv_m"]].iloc[cut:].values, df["y"].iloc[cut:].values
+    naive_te = df["naive"].iloc[cut:].values               # yesterday's value as the forecast
