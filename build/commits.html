+# RECORD STORE — read-only views over the ledgers (NIGHT BUNDLE 4/6 item 25)
+
+`scripts/record_store.py` reads the existing ledgers + exam outputs and writes ONE derived file,
+`site/data/record_store.json` (per engine / per pattern / per stock). It writes **no ledger** and invents
+nothing: a column a ledger does not carry, or a ledger with no rows, shows as `—` / 0. This page CITES the
+column mapping for every ledger shape so a reader can check each number against its source.
+
+## Shape 1 — the BOOK ledgers (parsed by header name, so a missing column is just `—`)
+
+Files: `reports/E10-BOOK-LEDGER.csv`, `reports/E11-BOOK-LEDGER.csv`, `reports/BOOK20-ADAPTIVE-LEDGER.csv`,
+`reports/books/E21-FLAT-LEDGER.csv`, `reports/books/E21-ADAPTIVE-LEDGER.csv`,
+`reports/books/QB-FLAT-LEDGER.csv`, `reports/books/QB-ADAPTIVE-LEDGER.csv`.
+
+| view field | ledger column | rule |
+|---|---|---|
+| engine (by_engine key) | `engine` | e.g. `QB-FLAT`, `E21-ADAPTIVE` |
+| pattern (by_pattern key) | `family` | e.g. `quiet-buying`, `overnight`; `—` if the ledger omits `family` (BOOK20-ADAPTIVE does) |
+| stock (by_stock key) | `stock` | the traded symbol |
+| closed | `status` ∈ {exited, closed, stopped, timed-out, target, stop} **and** a numeric `result_R` | counted as a settled trade |
+| open | `status` = open/blank **and** no `result_R` | counted, no P&L |
+| net_R | sum of `result_R` over closed rows | — |
+| wins / losses | `result_R` > 0 / < 0 | — |
+| net_rupees | sum of `result_rupees` | `has_rupees=false` and 0 if the ledger omits the column |
+
+## Shape 2 — the ROOF combined ledger (kept separate; a different metric)
+
+File: `reports/ROOF-COMBINED-LEDGER.csv` — header `engine,instrument,ts,side,mid_R,cross_R,status`.
+
+| view field | ledger column | rule |
+|---|---|---|
+| roof_by_engine key | `engine` | code mapped `1 → E1`; an unmapped code is shown as-is |
+| roof_by_stock key | `instrument` | a numeric **token**, resolved to a symbol via `engine1_rebuild.render.symbol`; the raw token if it cannot resolve (never guessed) |
+| net_cross_R | sum of `cross_R` (realistic, post-cost) | `mid_R` is the pre-cost column and is not summed here |
+
+## Shape 3 — the EXAM output
+
+File: `reports/LIVE-PATTERN-SET.json` — `exam[key] = {stock, family, net_per_trade_R, template}` per certified pattern.
+
+## NOT trade ledgers — named, excluded, not mapped (nothing invented)
+
+| file | why it is not a trade view |
+|---|---|
+| `reports/BOOK20-LEDGER.csv` | raw book20 fill log (`bid/ask/mid/cross`), no per-trade P&L column |
+| `reports/E19-FINDER-LEDGER.csv` | ruler discovery stats (`fires/hits/lb/pvalue`), not trades |
+| `reports/RULER-FACTORY-LEDGER.csv` | ruler discovery stats, not trades |
+
+## Wiring the v2 pages (the careful next step)
+
+`record_store.json` is the DATA SOURCE. Consuming it on a v2 engine page needs the engine-code→page mapping
+(e.g. `QB-*` = Dubai Strategies, `E21-*` = Overnight, `E10/E11` = E1 sizing books) — done with the owner's
+engine-name mapping so a number never lands on the wrong engine's page. Until a page is wired, it keeps its
+honest `—`. The `provenance` block in the JSON records every ledger read and its row count.

+"""R-RECORD-STORE / NIGHT BUNDLE 4 item 25 — READ-ONLY views over the existing ledgers + exam outputs, per
+engine / per pattern / per stock, as the data source for the v2 pages that otherwise show "—".
+
+Rules honoured (owner ruling NB4/NB6): read one ledger SHAPE at a time; the column mapping for each is CITED
+(in code + docs/RECORD-STORE.md); anything unmapped is "—", never invented; NO new ledger and NO write to any
+live ledger — this module only READS the ledgers and writes one derived file, site/data/record_store.json.
+
+Ledger shapes on disk (2026-09-23):
+  BOOK shape  trade_id,ts,status,stock,side,entry_price,stop,[family,weight,][mark_R,]risk_rupees,result_R,
+              result_rupees,[sizing,]cause,engine  — E10/E11/E21/QB/BOOK20-ADAPTIVE book ledgers. Parsed by
+              HEADER NAME so a missing column (e.g. BOOK20-ADAPTIVE has no 'family') simply yields "—".
+              -> per engine (col 'engine'), per pattern (col 'family'), per stock (col 'stock'); a CLOSED row
+                 (status in exited/closed/stopped/timed-out with a numeric result_R) contributes net_R / win /
+                 loss / net_rupees; a row with no result_R is counted 'open'.
+  ROOF shape  engine,instrument,ts,side,mid_R,cross_R,status  — ROOF-COMBINED-LEDGER. engine is a code (1->E1);
+              instrument is a numeric TOKEN (resolved to a symbol best-effort, else shown as the token). A
+              settled row's cross_R (realistic, post-cost) is summed per engine and per stock. Kept SEPARATE
+              from book trades (different metric).
+  NOT TRADES  BOOK20-LEDGER (raw fill log: ts,trade_id,state,cause,bid,ask,... — no per-trade P&L), and
+              E19-FINDER-LEDGER / RULER-FACTORY-LEDGER (ruler DISCOVERY stats: fires/hits/lb/pvalue). Excluded
+              from trade views and named in provenance with the reason — not mapped, not invented.
+  EXAM        reports/LIVE-PATTERN-SET.json — per pattern the exam's net_per_trade_R (the certified edge).
+"""
+from __future__ import annotations
+
+import csv
+import json
+import os
+
+_REPO = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
+OUT = os.path.join(_REPO, "site", "data", "record_store.json")
+
+BOOK_LEDGERS = [
+    "reports/E10-BOOK-LEDGER.csv", "reports/E11-BOOK-LEDGER.csv", "reports/BOOK20-ADAPTIVE-LEDGER.csv",
+    "reports/books/E21-FLAT-LEDGER.csv", "reports/books/E21-ADAPTIVE-LEDGER.csv",
+    "reports/books/QB-FLAT-LEDGER.csv", "reports/books/QB-ADAPTIVE-LEDGER.csv",
+]
+ROOF_LEDGER = "reports/ROOF-COMBINED-LEDGER.csv"
+NOT_TRADE_LEDGERS = {                                    # named, with the reason they are not trade views
+    "reports/BOOK20-LEDGER.csv": "raw book20 fill log (bid/ask/mid/cross), no per-trade P&L column",
+    "reports/E19-FINDER-LEDGER.csv": "ruler discovery stats (fires/hits/lb/pvalue), not trades",
+    "reports/RULER-FACTORY-LEDGER.csv": "ruler discovery stats (fires/hits/lb/pvalue), not trades",
+}
+CLOSED = {"exited", "closed", "stopped", "timed-out", "target", "stop"}
+ROOF_ENGINE = {"1": "E1"}                                # ROOF engine codes seen on disk
+
+
+def _num(x):
+    try:
+        return float(x)
+    except (TypeError, ValueError):
+        return None
+
+
+def _blank():
+    return {"closed": 0, "open": 0, "wins": 0, "losses": 0, "net_R": 0.0, "net_rupees": 0.0, "has_rupees": False}
+
+
+def _add(d, key, row):
+    b = d.setdefault(key or "—", _blank())
+    r = _num(row.get("result_R"))
+    status = (row.get("status") or "").strip().lower()
+    if r is None:
+        if status == "open" or status == "":
+            b["open"] += 1
+        return
+    b["closed"] += 1
+    b["net_R"] += r
+    b["wins"] += 1 if r > 0 else 0
+    b["losses"] += 1 if r < 0 else 0
+    rup = _num(row.get("result_rupees"))
+    if rup is not None:
+        b["net_rupees"] += rup
+        b["has_rupees"] = True
+
+
+def _read_csv(rel):
+    path = os.path.join(_REPO, rel)
+    try:
+        with open(path, encoding="utf-8") as f:
+            return list(csv.DictReader(f))
+    except Exception:
+        return None
+
+
+def _resolve_token(tok):
+    try:
+        from engine1_rebuild import render
+        return render.symbol(int(tok))
+    except Exception:
+        return str(tok)
+
+
+def build(write=True):
+    by_engine, by_pattern, by_stock = {}, {}, {}
+    prov = {"book_ledgers": {}, "roof_ledger": {}, "not_trade_ledgers": NOT_TRADE_LEDGERS,
+            "column_map": {"engine": "col 'engine'", "pattern": "col 'family'", "stock": "col 'stock'",
+                           "net_R": "sum of col 'result_R' over closed rows",
+                           "net_rupees": "sum of col 'result_rupees' (— if the ledger omits it)",
+                           "closed": "status in %s" % sorted(CLOSED), "open": "status 'open' / blank + no result_R"}}
+    for rel in BOOK_LEDGERS:
+        rows = _read_csv(rel)
+        if rows is None:
+            prov["book_ledgers"][rel] = "unreadable — skipped"
+            continue
+        prov["book_ledgers"][rel] = "%d rows" % len(rows)
+        for row in rows:
+            _add(by_engine, (row.get("engine") or "—").strip(), row)
+            _add(by_pattern, (row.get("family") or "—").strip(), row)
+            _add(by_stock, (row.get("stock") or "—").strip(), row)
+
+    roof_by_engine, roof_by_stock = {}, {}
+    rows = _read_csv(ROOF_LEDGER)
+    if rows is None:
+        prov["roof_ledger"][ROOF_LEDGER] = "unreadable — skipped"
+    else:
+        prov["roof_ledger"][ROOF_LEDGER] = "%d rows; cross_R summed per engine + per resolved instrument" % len(rows)
+        for row in rows:
+            eng = ROOF_ENGINE.get((row.get("engine") or "").strip(), (row.get("engine") or "—").strip())
+            cr = _num(row.get("cross_R"))
+            if cr is None:
+                continue
+            roof_by_engine.setdefault(eng, {"rows": 0, "net_cross_R": 0.0})
+            roof_by_engine[eng]["rows"] += 1
+            roof_by_engine[eng]["net_cross_R"] += cr
+            sym = _resolve_token(row.get("instrument"))
+            roof_by_stock.setdefault(sym, {"rows": 0, "net_cross_R": 0.0})
+            roof_by_stock[sym]["rows"] += 1
+            roof_by_stock[sym]["net_cross_R"] += cr
+
+    exam = {}
+    try:
+        d = json.load(open(os.path.join(_REPO, "reports", "LIVE-PATTERN-SET.json"), encoding="utf-8"))
+        for key, p in (d.get("patterns") or {}).items():
+            exam[key] = {"stock": p.get("stock"), "family": p.get("family"),
+                         "net_per_trade_R": p.get("net_per_trade_R"), "template": p.get("template")}
+        prov["exam"] = "reports/LIVE-PATTERN-SET.json — %d patterns (net_per_trade_R per pattern)" % len(exam)
+    except Exception:
+        prov["exam"] = "reports/LIVE-PATTERN-SET.json unreadable"
+
+    def _round(d):
+        for b in d.values():
+            if "net_R" in b:
+                b["net_R"] = round(b["net_R"], 4)
+            if "net_rupees" in b:
+                b["net_rupees"] = round(b["net_rupees"], 2)
+            if "net_cross_R" in b:
+                b["net_cross_R"] = round(b["net_cross_R"], 4)
+        return d
+    out = {"generated": __import__("datetime").datetime.now().isoformat(),
+           "by_engine": _round(by_engine), "by_pattern": _round(by_pattern), "by_stock": _round(by_stock),
+           "roof_by_engine": _round(roof_by_engine), "roof_by_stock": _round(roof_by_stock),
+           "exam": exam, "provenance": prov,
+           "note": "READ-ONLY views over existing ledgers + exam outputs; no ledger is written. '—' where a "
+                   "ledger omits a column or holds no rows; nothing is invented (NB4/NB6 item 25)."}
+    if write:
+        os.makedirs(os.path.dirname(OUT), exist_ok=True)
+        with open(OUT, "w", encoding="utf-8") as f:
+            json.dump(out, f, indent=1, ensure_ascii=False)
+    return out
+
